# Software Onboarding

## **Welcome to the Software Team!**

We're excited to have you on board!
In this division, you'll dive deep into the software side of robotics—learning how to program, operate, and understand our rover.
You'll gain hands-on experience with the core tools and concepts that power modern robotics systems.

## **Tools You'll Be Working With:**

- **Ubuntu 22.04 (Jammy Jellyfish)**  
  Our preferred open-source Linux distribution for robotics development.
- **Virtual Machines (VMs)**  
  If you cannot run Ubuntu directly on your device, we use **Oracle VirtualBox** or **UTM** (for Mac) for our development environments.
- **ROS 2 (Humble)**  
  The Robot Operating System (ROS) enables communication between various parts of the robot. It's central to everything we build.
- **C++ and Python**  
  Our primary programming languages for building robot behavior, control algorithms, and infrastructure.
- **GitHub**  
  For version control, collaboration, and managing the entire codebase. Every member contributes and pulls from our shared repositories.

## **Attendance & Participation**

- **Saturdays** are our main workdays. Please plan to be present in person.
- If you cannot attend, communicate **ahead of time** and **complete any required tasks** before the weekly meeting.
- You are welcome to work from home, but:
    - Always sync with your leads before deploying anything to the rover.
    - Keep your work on the GitHub repository up to date.
    - Be proactive. If you finish tasks early, ask for new ones or explore beyond the basics.
    - Respect hardware safety. Test thoroughly in simulation before running code on the rover.
