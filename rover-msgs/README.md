# Rover Messages

This package contains custom shared messages & interfaces.

## Messages

- `ImageDetection`: An image detection with a label, confidence, and min/max coordinate.
- `ImageDetectionArray`: An array of image detections.

## Actions

- `ScienceSpectrometerScan`: Initiates a scan with the spectrometer in the science payload.

## Services

- `SetSILStatus`: Sets the colour of SIL.
