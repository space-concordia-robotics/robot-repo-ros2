Upload the solidworks export folder into URDF_Imports
-- Meshes should be under your imported folder, in their meshes folder
-- .URDF files should be under the imported folder, in their urdf folder
** URDF_Iports/Intro_URDF shows the ideal directory organization


Run the launcher: ros2 launch urdf_viewer_pkg urdf_viewer_launch.xml

Select the desired URDF to load from the URDF_Imports folder as prompted in the terminal
